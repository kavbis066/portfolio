Award-Winning

How Bad is Delhi's Air?

Award-winning data visualization (Best Data Visualization, WAN INFRA 2025). Built an interactive visualization analyzing 11 years of air quality data across Indian cities using GSAP-powered animations and real-time API integration. Hundreds of SVG rectangles dynamically transform into bar charts revealing long-term PM2.5 trends, while an interactive hero carousel enables seamless exploration across multiple cities with hourly updates from IQAir's API. This project demonstrates how animation, real-time data, and intuitive interaction design transform environmental data into engaging, accessible storytelling.
